# API Contracts: Сайт бара с меню и клиентским кабинетом

**Feature**: [spec.md](../spec.md) | **Data model**: [data-model.md](../data-model.md) | **Date**: 2026-07-23

Next.js Route Handlers (`app/api/**/route.ts`). Формат ответа — JSON; ошибки — `{ "error": { "code": string, "message": string } }` с соответствующим HTTP-статусом. Эндпоинты, требующие авторизации, помечены 🔒 (сессионная cookie Auth.js); её отсутствие → `401`.

## Меню (User Story 1, FR-001…FR-003, FR-019…FR-021)

| Метод | Путь | Назначение | Auth |
|---|---|---|---|
| GET | `/api/menu/categories` | Дерево категорий/подкатегорий (FR-001) | — |
| GET | `/api/menu/items?categoryId=&search=` | Список позиций по (под)категории и/или поисковому запросу (FR-002, FR-003, FR-019) | — |
| GET | `/api/menu/items/popular` | Топ-10 позиций, отсортированных по `likesCount` (FR-021) | — |
| POST | `/api/menu/items/:id/like` | Toggle-лайк для текущего `visitor_id` (создаёт cookie при отсутствии) (FR-020) | — |

Ошибки: пустая категория/пустой поиск → `200` с пустым массивом `items: []` (не `404`), в соответствии с Edge Cases spec.md.

## Личный кабинет: чеки и бонусы (FR-007, FR-009, FR-010, FR-011, FR-016, FR-025)

| Метод | Путь | Назначение | Auth |
|---|---|---|---|
| GET | `/api/account/receipts` | История чеков текущего пользователя (пусто при первом входе — FR-016) | 🔒 |
| GET | `/api/account/receipts/:id` | Полный состав конкретного чека (FR-007) | 🔒 |
| GET | `/api/account/bonuses` | Текущий баланс (сумма `BonusTransaction`) + история операций (FR-010) | 🔒 |

`GET /api/account/receipts/:id` и `/api/account/bonuses` возвращают `403`, если чек/операция принадлежат другому пользователю (FR-011) — id всегда проверяется вместе с `userId` сессии, не доверяем только параметру пути.

Эндпоинтов на списание бонусов нет — FR-025 фиксирует, что списание всегда офлайн.

## Административный инструмент (`/admin`, только `User.isAdmin = true`)

Не для гостей — внутренний инструмент персонала (см. spec.md → «Административный инструмент»). Доступ проверяется дважды: `proxy.ts` на уровне страниц `/admin/*` и `requireAdmin()` (`lib/require-admin.ts`) на уровне каждого API-роута — `401`, если не авторизован, `403`, если авторизован, но не админ.

| Метод | Путь | Назначение | Auth |
|---|---|---|---|
| GET | `/api/admin/bonus-settings` | Текущая ставка начисления бонусов (%) | 🔒 admin |
| PATCH | `/api/admin/bonus-settings` | Изменить ставку (0–100) | 🔒 admin |
| POST | `/api/admin/receipts` | Внести чек по телефону гостя (список позиций) — создаёт `Receipt`+`ReceiptItem` и автоматически начисляет `BonusTransaction` по текущей ставке | 🔒 admin |

`POST /api/admin/receipts` → `404 { code: "USER_NOT_FOUND" }`, если по телефону нет зарегистрированного гостя.
